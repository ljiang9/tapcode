# tapcode 敲击码

终端里的敲击码(Tap Code)编解码器,纯标准库。

## 玩法

敲击码用 5×5 波利比乌斯方阵表示字母:先敲"行数",停顿,再敲"列数"。
字母用 `.` 表示敲击,例如 `S` = 第 4 行第 3 列 = `.... ...`。

```bash
python -m tapcode "SOS"                 # 编码
python -m tapcode --decode ".... ... ... .... .... ..."
echo "HELLO WORLD" | python -m tapcode  # 管道输入
```

## 设计取舍

- **I/J 合并**:5×5 方阵只能装 25 个字母,国际通用约定把 I 和 J 合并为一格
  (`(2,4)` 解码显示为 `I/J`)。编码时 J 与 I 敲法相同。
- **单词分隔**:字母之间用双空格,单词之间用三空格,保证可逆。
- **解码歧义**:解码 `(2,4)` 永远显示 `I/J`,无法还原原文是 I 还是 J——这是编码本身
  的信息丢失,不是 bug。

## 已知局限

- 只支持 A-Z(大小写均可),数字/标点/中文会报错。
- 视觉演示用,无音频敲击。
- 解码时 `(2,4)` 固定显示 `I/J`。
